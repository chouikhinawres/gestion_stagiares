# 🎓 Internship Management System

A web application dedicated to the **management and monitoring of interns** within an organization.

The project centralizes information related to interns, supervisors, absences, and internship administration through a web-based interface.

## 📌 Features

### 👨‍🎓 Intern Management

* Add an intern
* Edit intern information
* View the list of interns
* Delete an intern

### 👨‍💼 Supervisor Management

* Add a supervisor
* Edit supervisor information
* View supervisors
* Delete a supervisor

### 📋 Internship Management

* Assign a supervisor to an intern
* Create and view internship records
* Edit internship information
* Monitor internships

### 🕐 Absence Management

* Submit absence requests
* Process absence requests

### 🔐 Authentication

* User login
* Access control to application features

### 📁 File Management

* Upload documents
* Store files related to internships

## 🛠️ Technologies

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/chouikhinawres/gestion_stagiares.git
```

### 2. Place the Project in XAMPP

Copy the project folder into:

```text
C:\xampp\htdocs\
```

### 3. Start XAMPP

Start the following services:

* **Apache**
* **MySQL**

### 4. Configure the Database

Create a MySQL database using **phpMyAdmin**, then configure the database connection settings in:

```text
config/
```

### 5. Run the Application

Open your browser and go to:

```text
http://localhost/gestion_stagiares/
```

## 🎯 Project Objective

The objective of this project is to simplify **internship management** by centralizing information about interns, supervisors, internship records, and absences within a single web application.
